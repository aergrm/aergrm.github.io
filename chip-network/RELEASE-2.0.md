# Evidence release 2.0

This release separates three dated evidence layers:

- 2025 firm-network findings reported by Köse et al. (2026)
- official semiconductor cooperation records through July 2026
- a fixed 2024 CEPII BACI bilateral customs-trade baseline

The firm layer reports only published findings and does not reconstruct the authors' non-public edge list. The dedicated GitHub Pages workflow publishes this directory to `gh-pages/chip-network` while preserving the rest of the existing site.
